# React Testing Standards

Frontend must include automated tests.

---

## Test Framework

Use:

- Jest
- React Testing Library

---

## Test Types

Components must include:

- rendering tests
- interaction tests

---

## Component Isolation

Tests must focus on component behavior.

Avoid testing implementation details.

---

## Mocking

API calls must be mocked.

Components must not depend on live backend services.

---

## Coverage

Critical UI flows must have tests.

Examples:

- BU upload
- dashboard rendering
